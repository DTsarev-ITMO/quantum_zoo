# Квантовый зоопарк
Квантовый зоопарк для проверки гипотезы о квантовоподобном поведении социальных систем.

## Ключевая идея: 

У нас есть статьи (добавить ссылки на статьи), в которых мы моделируем динамику социальной сети.
Мы используем формулы квантовой физики, много усредняем, получаем определенные эффекты. 
На каком основании мы это делаем? Имеют ли эти эффекты отношение к реальности?

Мы стесняемся термина "квантовый", используем "квантово-подобный" и подобные.

### Гипотеза 1:
Физические формулы хорошо описывают нашу социальную систему.

Для проверки этой гипотезы нужно:
1. Создать множество атомарных классических агентов
2. Поместить их в нашу сеть с нашими параметрами
3. Просимулировать взаимодействие и повторить результаты, полученные ранее.

### Гипотеза 2:
Квантовоподобные эффекты (квантовые эффекты?) возникают в системе в следствие ее сетевой структуры. 
Агентам не нужно быть квантовыми, чтобы система была квантовой.

Для проверки этой гипотезы нужно:
1. Построить модель с классическими агентами
2. Построить модель с квантовыми агентами
3. Сравнить результаты
4. Разработать критерии квантовости системы
5. Оценить квантовость социальной системы
